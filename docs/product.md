# 产品 SKILL · 产品设计描述

> 目标文件：`src/index.html` — 墨弈围棋

---

## 1. 产品定位

**产品名称**：墨弈（Mo Yi）—— 围棋在线对弈工具

**核心价值主张**：一款开箱即用的围棋对弈页面，无需注册、无需下载，打开即下。以水墨国风提供沉浸式对弈体验。

**目标用户画像**：

| 用户类型 | 场景 | 核心需求 |
|----------|------|---------|
| 围棋爱好者 | 通勤/碎片时间想下一盘 | 快速开局、标准规则、悔棋功能 |
| 围棋初学者 | 学习规则、练习 | 规则提示、视觉辅助（悬停预览、劫争标示） |
| 棋友对弈 | 面对面时用一个屏幕下棋 | 两人轮流在同一设备落子，棋谱记录 |
| 围棋内容创作者 | 录制教学/复盘视频 | 美观的棋盘视觉效果，棋谱导出可能性 |

## 3. 用户流程

### 主流程：完成一局围棋

```
1. 用户想下一盘棋 → 打开页面 → 系统初始化 19×19 棋盘，黑方先行，显示"黑方落子"
2. 用户思考落子位置 → 鼠标在棋盘移动 → 系统实时显示半透明预览棋子
3. 用户点击交叉点 → 系统校验合法性 → 落子（弹性动画）→ 检查提子/劫争 → 更新提子数 → 切换白方
4. 用户（白方）重复 2-3
5. 用户想悔棋 → 点击"悔棋一手"或按 U → 系统回退上一手状态
6. 用户不想落子 → 点击"虚着"或按 P → 系统记录 Pass，切换玩家
7. 用户想重新开始 → 点击"新对局"或按 N → 系统重置棋盘
8. 用户想换小棋盘 → 点击 9×9 → 系统重新初始化 9×9 棋盘
```

### 边界情况

| 场景 | 系统行为 |
|------|---------|
| 在已有棋子处落子 | Toast "此处已有棋子"，落子被拒绝 |
| 在劫争点落子 | Toast "劫争禁着·不可即提"，落子被拒绝 |
| 自杀落子 | Toast "禁着点·不可自杀"，落子被拒绝 |
| 提子 | Toast "提 N 子"，更新提子计数 |
| 空栈悔棋 | Toast "已无棋可悔" |
| 首次打开（空棋谱） | 显示"尚无落子，请黑方先行..."占位 |

## 4. 设计决策与取舍

### 决策 1：单 HTML 文件，无后端

- **决策**：整个应用是一个 HTML 文件，不依赖后端服务
- **理由**：零部署成本，打开即用；围棋规则在客户端即可完整实现
- **舍弃了什么**：不提供联网对战、AI 对弈、棋谱持久化（LocalStorage 可加但未加）
- **后续考量**：如需联网对战，需要引入 WebSocket 和服务端棋局管理

### 决策 2：Canvas 绘制棋盘而非 DOM 元素

- **决策**：使用 `<canvas>` 绘制棋盘、棋子、标记，而非 DOM 元素
- **理由**：围棋棋盘有大量交叉点（19×19=361），Canvas 在大数量级下性能更好；落子动画、渐变等视觉效果 Canvas 更灵活
- **舍弃了什么**：失去 DOM 元素的可访问性（无法直接添加 `aria-label`、无法被屏幕阅读器识别）
- **后续考量**：如需无障碍支持，需叠加 DOM 层或提供纯文本棋谱替代

### 决策 3：水墨国风主题

- **决策**：主题采用深色底 + 琥珀色 + 朱砂点缀的水墨风格
- **理由**：围棋本身具有东方文化属性，水墨风格增强沉浸感；深色背景减少长时间对弈的眼疲劳
- **舍弃了什么**：国际化风格偏好（简约/现代/高对比度等方案未提供）
- **后续考量**：若需多主题切换，引入 CSS 自定义属性体系即可扩展

### 决策 4：不实现终局数子与计分

- **决策**：只提供落子、提子、虚着，不实现终局判定、数子、贴目等
- **理由**：终局规则复杂（虚着连续两次结束 + 双方同意），且用户使用场景通常自己判断胜负
- **舍弃了什么**：自动化计分、让子、贴目等比赛级功能
- **后续考量**：如需实现，需引入中国规则/日韩规则的计分逻辑

### 决策 5：完整历史栈而非单步撤销

- **决策**：使用数组 `history` 保存每一步的完整棋盘快照，而非只存差异
- **理由**：实现简单可靠，悔棋操作无需增量计算；棋盘 19×19 每个快照约 2KB，对内存无压力
- **舍弃了什么**：无法前进（下一步）只支持后退

## 5. 内容策略

**文案风格**：古风典雅，短句为主。

| 位置 | 文案 | 风格说明 |
|------|------|---------|
| 标题 | "墨弈" | 二字命名，含蓄有力 |
| 副标题 | "一子千秋·黑白方寸" | 四字对仗，营造格局感 |
| 黑方白方 | "玄" / "素" | 单字雅称替代"黑"/"白" |
| 引导语 | "执黑先行" / "执白后行" | 简洁说明规则 |
| 空状态 | "尚无落子，请黑方先行..." | 告知用户当前状态和下一步 |
| 规则说明 | "黑先白后，轮流落子。气尽提子，禁着自杀，劫争不可即提。" | 四句十六字，完整概括核心规则 |
| 快捷键 | 悔棋(U) / 新对局(N) / 虚着(P) | 使用按键名 + 中文操作 |

**术语表**：

| 中文 | 英文/代码 | 含义 |
|------|----------|------|
| 气 | liberty | 棋子相邻的空交叉点 |
| 提子 | capture | 移走气尽对方棋子 |
| 劫争 | ko | 禁止立即回提一子的局面 |
| 虚着 | pass | 放弃落子 |
| 星位 | star point | 棋盘上的星标位置 |
| 手数 | move number | 已落子数量 |
