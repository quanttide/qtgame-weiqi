## 1. 布局结构

**布局骨架**：标题 → 装饰线 → 工具条 → 三栏网格。工具条（对局控制 + 棋盘尺寸）独立于网格之外，位于标题与棋盘之间。

**响应式行为**：

| 断点 | 布局变化 |
|------|---------|
| 默认（移动端） | 单列：标题 → 工具条 → 棋盘 → 黑方 → 白方 → 棋谱 |
| `lg:`（≥1024px） | 三栏网格：左栏 260px / 中栏 1fr / 右栏 260px；快捷键文字在 `md:` 下显示 |

- 布局系统：Tailwind Grid（`grid-cols-1 lg:grid-cols-[260px_1fr_260px]`）+ Flexbox 子布局
- 棋盘使用 `aspect-ratio: 1` 保持正方形，`max-width: 720px` 限制最大尺寸
- 浮动墨晕装饰使用 `position: fixed` 脱离文档流，不参与布局

## 3. 样式方案

**主题总览**：「水墨风」— 深色宣纸底色（`#0f0a07`）、琥珀色棋盘（`#d4a76a`）、朱砂点缀（`#c93838`）、金色高亮（`#d4a020`）。

**关键样式技术点**：

| 视觉效果 | 实现方式 |
|----------|---------|
| 宣纸纹理背景 | 三层 `radial-gradient` + 一层 `linear-gradient`，模拟纸张晕染质感 |
| 浮动墨晕 | 三个 `position: fixed` 的圆形容器，`filter: blur(80px)` + CSS `@keyframes` 浮动动画 |
| 棋盘木纹 | Canvas 程序化绘制 — 40 条随机贝塞尔曲线，深浅交替，`globalAlpha = 0.08` |
| 面板质感 | `backdrop-filter: blur(12px)` 毛玻璃 + 渐变半透明背景 + 顶部 1px 高光线 |
| 棋子立体感 | `RadialGradient` 三点高光：高光点、主体、暗部边缘 + `shadowBlur` 投影 + 边缘描边 |
| 脉冲外圈 | `@keyframes pulse` — `scale`+`opacity` 交替，`2s infinite` |

- 样式实现方式：CSS 自定义属性（`:root` 颜色变量）+ Tailwind 工具类 + 内联 CSS 样式 + Canvas API 绘图
- 字体：标题 `ZCOOL XiaoWei`（衬线书法体），正文 `Noto Sans SC`（无衬线）

## 4. 交互与动效

| 交互 | 触发方式 | 行为逻辑 | 视觉反馈 |
|------|---------|---------|---------|
| 落子 | 鼠标点击 / 触摸 | 检查位置合法性 → 提子判断 → 劫争判断 → 更新状态 | 弹性缩放动画（0→118%→100%，320ms）+ Toast 提子数提示 |
| 悬停预览 | 鼠标移动 | 实时计算鼠标所在交叉点，非空/劫争点时隐藏 | 半透明棋子预览（`globalAlpha = 0.45`） |
| 悔棋 | 按钮 `U` / 键盘 `U` | 从 history 栈弹出上一状态，恢复棋盘 | Toast "已无棋可悔"（空栈时） |
| 虚着 | 按钮 `P` / 键盘 `P` | 记录 Pass，切换玩家，清空劫争/最后一手 | Toast 通知轮换 |
| 新对局 | 按钮 / 键盘 `N` | 重置所有状态，保持当前棋盘尺寸 | Toast "新对局开始" |
| 切换棋盘尺寸 | 点击 9/13/19 按钮 | 重置棋盘并切换尺寸 | 按钮 active 状态切换 + 标题更新 |
| Toast 通知 | 自动触发 | 3 种类型（info/error/success），1.8s 自动消失 | 上滑淡入 + 下滑淡出过渡 |

**动画系统**：

- 落子动画：`requestAnimationFrame` 驱动，320ms 弹性缩放曲线（0→0.65→1.0）
- 当前玩家指示器：`@keyframes pulse` 脉冲光晕
- 墨晕浮动：三段不同速度/路径的 `@keyframes`（18s/22s/25s）
- 按钮 hover：`translateY(-1px)` + `box-shadow` + 背景色渐变过渡

## 5. 可访问性与细节

- **语义化 HTML**：使用 `<main>`、`<header>`、`<aside>`、`<section>`、`<footer>` 等语义标签
- **语言声明**：`<html lang="zh-CN">`
- **键盘快捷键**：U（悔棋）、N（新对局）、P（虚着），且在输入框/文本域中禁用
- **触摸支持**：`touchstart` 事件绑定，`passive: false` 防止滚动冲突
- **空状态**：棋谱区无落子时显示"尚无落子，请黑方先行..."占位文案
- **边界提示**：落子位置校验、劫争禁着提示、已有棋子提示、空栈悔棋提示，均通过 Toast 反馈
- **Canvas 缩放适配**：`getCanvasCoord` 中根据 `canvas.width / rect.width` 计算比例，适配 Retina/缩放屏幕
- **滚动条美化**：自定义 `::-webkit-scrollbar` 颜色匹配主题

> **未覆盖**：无 ARIA 属性（`role`、`aria-label`），无屏幕阅读器适配；无多语言/国际化支持。
