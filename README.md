# 量潮围棋 · 墨弈

一款水墨国风围棋在线对弈工具。打开即下，无需注册。

## 快速开始

在浏览器中打开 `src/index.html` 即可。

## 功能

- 标准围棋规则：落子、提子、劫争检测、自杀禁着
- 悔棋、虚着（Pass）
- 棋盘尺寸切换：9×9 / 13×13 / 19×19
- 落子动画、悬停预览、实时棋谱
- 键盘快捷键：U 悔棋 / N 新对局 / P 虚着
- 移动端触摸支持

## 开发模式

本项目围绕**产品蓝图**循环迭代：

```
产品蓝图（多视角定义）
    → AI 写代码
    → 多视角 dev 文档解释（校验回蓝图）
    → 反馈修正蓝图或代码
    → ...
```

三个视角的框架定义在 `.agents/product-blueprint/` 下：

| 视角 | 文件 | 核心问题 |
|------|------|---------|
| 产品 | `product.md` | 做的是不是用户要的？ |
| 设计 | `design.md` | 体验是否到位？ |
| 技术 | `architecture.md` | 做得对不对？ |

每次循环的分析产物输出到 `docs/dev/`。
